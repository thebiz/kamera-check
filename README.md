# kamera-check

Experimentelle Zoom-Kamera für Android (getestet auf Poco X7 Pro).

- Live-Vorschau mit Zoom bis 10× (Regler, Schnellwahl, zwei Finger)
- Tippen zum Fokussieren, Doppeltippen für Autofokus, Makro-Schalter
- Auslöser schießt eine Bildserie (8–12 Bilder), richtet sie aufeinander aus und verrechnet sie auf ein feineres Raster (Mehrbild-Superauflösung) – speichert zum Vergleich Einzelbild und Mehrbild-Ergebnis unter *Bilder/Kamera-Check*
- „Check“ zeigt, welche Kamera-Funktionen das Handy freigibt

**Neueste APK:** [kamera-check.apk](https://github.com/thebiz/kamera-check/releases/latest/download/kamera-check.apk)
