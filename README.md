# kamera-check

Kleine Android-Test-App: liest aus, welche Kamera-Funktionen das Handy für eigene Apps freigibt – RAW, manueller Sensor, volle Sensorauflösung, Zoombereich, Naheinstellgrenze (Makro), versteckte Kameras.

Erste Etappe auf dem Weg zur KI-Zoom-Kamera.

**Neueste APK:** [kamera-check.apk](https://github.com/thebiz/kamera-check/releases/latest/download/kamera-check.apk)
